# JEP Core 0.7 positioning

JEP is the event layer for verifiable judgment-related statements. It defines
J/D/T/V, stable Event Identity, signing input, artifact hashes, independent
checks and scoped idempotent acceptance. It does not establish external truth
or require a particular identity, authorization, runtime or chain system.

Use the [current overview](ONE-PAGE-OVERVIEW.md), [architecture](architecture/README.md)
and [published sources](SPECIFICATION-SOURCES.md).

[Historical 0.6 positioning](historical/0.6/POSITIONING.md) is retained separately.
