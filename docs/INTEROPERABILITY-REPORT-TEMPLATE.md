# Current interoperability report entry

For Core 0.7, use the [report guide](INTEROPERABILITY-REPORT.md), the
[machine-readable schema](../schemas/jep-byoi-report.schema.json), and the
[BYOI runner](BYOI-CONFORMANCE.md). The runner generates the result rather than
asking contributors to manually assert that each check passed.

The previous [0.6 report template](historical/0.6/INTEROPERABILITY-REPORT-TEMPLATE.md)
is historical and must not be used to claim current conformance.
